## Demonstrated failure and repair

The private-process regressions failed on the original bridge for both direct
model cancellation and synthetic failure followed by cancellation. Both exceeded
the 3-second reply deadline and emitted
`g_dbus_method_invocation_return_gerror: assertion 'error != NULL' failed`.
This locates a product completion failure, independently of the historical Python
helper hang. The helper itself waited without a deadline; no separate helper-only
cause is asserted for the original observation.

The coordinator already completed false exactly once and reset the prompt.
`Completion::finish(false)` incorrectly returned a successful GTask containing false.
[libpolkit's auth_cb](https://github.com/polkit-org/polkit/blob/master/src/polkitagent/polkitagentlistener.c)
interprets a false finish result as an error and uses its GError for the D-Bus reply.
Returning `POLKIT_ERROR_CANCELLED` via `g_task_return_error` supplies that error.
Success still returns true; the existing atomic completion guard and coordinator
request/generation guards remain responsible for exactly-once and stale-callback
handling. No public API or production test controls changed.

`tests/polkit_cancellation_agent.cpp` links the real bridge/coordinator with a
synthetic session exclusively into a test executable. The private authority fixture
checks the actual pending BeginAuthentication error and then a second `gdbus`
requester's NormalExit/1 before its deadline, with the same agent still running.
Both direct/failure modes reject duplicate cancellation and late session callbacks.
The production variant uses two identities and authority cancellation without PAM;
it also verifies normal requester exit. Shutdown now asserts the typed pending
reply, not just unregistration/exit. Bridge tests cover failure-to-cancel, a queued
successor, stale callbacks, and active/queued shutdown completion once.

The test's first production probe used empty identities, which libpolkit rejects
before calling the bridge. It was replaced with valid identity selection and
CancelAuthentication; that invalid-input probe is not claimed as product evidence.
