## Reproduction and contract

Launcher.qml browse/app search delegates unconditionally call setSelectedIndex
onHoveredChanged. Thus stationary pointer enter from opening/filtering/layout can
change the Enter target. Preserve this trigger in the offscreen fake-service
harness before implementation; never launch real applications in tests.

Consume provider `HnInputInteraction` attached to launcher root. Opening/reopening
suppresses hover and resets intended selection. Keyboard navigation/filtering
retains keyboard authority until pointerMoved. Hit-test visible current result
layout at the delivered window scene point, including movement within an already
hovered row; ignore headers, empty space, hidden/disabled/nonselectable rows.
Browse, app search and action rows retain immediate direct click activation.

Provider signal contract is recorded in holonight-qt UQC-213. No local duplicate
input state. Validate stationary opening, navigation, movement, clicks, reentry,
animations, filtering and reopen with a fake launch service, including Enter target.
Run shell tests, QML lint/types and relevant source/installed launch checks.
F07 remains open until automated and targeted manual confirmation. No ecosystem
acceptance is implied.

## Implementation and local verification — 2026-09-12

Launcher root consumes the shared window movement signal and hit-tests the active
ListView plus actual visible delegate bounds. Search action children are included;
headers, empty space and disabled/filtered rows do not select. Both unconditional
hover handlers are removed. Opening/reopening/reset explicitly suppress hover;
reset chooses the first result (or -1 when empty). Query and local filter changes
suppress stale hover. Direct row activation stays unchanged. Existing filter and
service navigation semantics otherwise remain in their owning layers.

The fake launcher now supplies real model roles, navigation and launch recording.
No process launch exists in that fake. Offscreen tests cover stationary creation,
reopen animation, mouse-to-keyboard switching, movement inside an already-hovered
row, immediate click, reentry, query/filter changes, headers/empty/disabled rows,
action rows and filtered hit geometry. Enter target is asserted through the fake.
